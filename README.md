# SpotifyClone
A fully responsive Spotify Clone built with a clean UI and smooth user experience. Browse songs, play/pause audio, navigate between pages, and enjoy a Spotify-like interface recreated with modern web technologies.
✨ Features

🎵 Music player with play/pause & seek

📂 Song list with thumbnails

📱 Fully responsive UI

🔁 Next/Previous track controls

🎚 Volume control

⚡ Fast & clean design

📌 Tech Stack

-HTML5

-CSS3 Bootsharp
